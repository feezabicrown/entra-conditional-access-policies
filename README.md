# Microsoft Entra ID Conditional Access Policies

## Project Overview

I configured three Conditional Access policies in Microsoft Entra ID to strengthen authentication security, block legacy authentication, and restrict administrative access to compliant devices.

## Business Scenario

SouthWest Tech needed stronger access controls to reduce unauthorized access, protect user accounts, and secure administrative access to company resources.

## Tools Used

- Microsoft Entra ID
- Conditional Access
- Multi-Factor Authentication (MFA)

## What I Built

### 1. Block Legacy Authentication

I configured a Conditional Access policy to block legacy authentication methods that do not support modern authentication controls.

[View Lab Documentation](https://github.com/feezabicrown/CA-Policy-Blocking-Legacy-Authentication)

### 2. Require Multi-Factor Authentication

I configured a Conditional Access policy requiring MFA for selected users to strengthen account security.

[View Lab Documentation](https://github.com/feezabicrown/CA-Policy-Require-MFA)

### 3. Require Compliant Devices for Administrators

I configured a Conditional Access policy requiring a compliant device for administrative access.

[View Lab Documentation](https://github.com/feezabicrown/CA-policy-admin-device-compliance)

## Security Lessons Learned

Conditional Access helps protect organizational resources by enforcing access requirements based on user identity, device compliance, and authentication conditions. Using multiple policies provides better control over how users access company resources.
